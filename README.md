# Sakura Dashboard prototype
Bazzite KDE / Wayland. Install CAVA and playerctl if missing (rpm-ostree install cava playerctl; reboot or apply-live as appropriate). Run ./run.sh. Drag the window using KDE's window move shortcut (Meta + left drag), F11 fullscreen, Escape quit. No autostart or automatic monitor selection yet. GPU data uses nvidia-smi; music metadata uses playerctl; audio uses CAVA PulseAudio compatibility. No simulated audio when CAVA is unavailable. Python virtual environment installs Qt/PySide6 and psutil. Not tested on target hardware. Album art and mode switching are not implemented yet.
